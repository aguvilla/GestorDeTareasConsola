# Gestor de Tareas (Consola)

Aplicación de consola escrita en C# para gestionar tareas simples.

## Funcionalidades
- Crear tareas con descripción
- Listar tareas pendientes y completadas
- Marcar tareas como completadas
- Eliminar tareas por ID

## Cómo ejecutarlo
1. Cloná el repositorio
2. Abrí el proyecto en Visual Studio
3. Ejecutá el archivo `Program.cs`
